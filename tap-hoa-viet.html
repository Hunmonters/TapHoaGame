Tạp hóa của những bản Việt hóa game. Hàng do cộng đồng dịch, chơi thử và cập nhật. Chọn game, kiểm phiên bản, tải về, chơi.

Xem kệ hàng

Chỉ phát hành bản vá dịch. Không chứa file game gốc.

Kệ hàng

Bấm vào bìa để mở cửa sổ chi tiết. Nhấn Space khi đang chọn một bìa để xem nhanh. Bấm chuột phải để mở menu tác vụ.

    Chưa thấy hàng nào khớp

    Thử bỏ bớt bộ lọc.

    Cách dùng hàng

    Ba bước từ lúc tải về tới lúc chơi. Mỗi game có thêm mục Đổi trả để gỡ bản dịch nếu cần.

    Antivirus báo nhầm? So mã SHA-256 của file tải về với mã ghi ở cửa sổ chi tiết, mục Thông tin. Hai mã trùng nhau nghĩa là file còn nguyên vẹn.

    TẠP HÓA VIỆTHóa đơn cài đặt
    1. Kiểm hàng, sao lưu

      Nhập phiên bản game vào mục Kiểm hàng. Rồi chép thư mục game, hoặc riêng file ngôn ngữ gốc, sang nơi khác.

    2. Chép bản vá

      Giải nén file tải về, chép đè vào thư mục cài đặt. Mục Đổi trả liệt kê đúng những file sẽ bị thay đổi.

    3. Chọn Tiếng Việt

      Mở game, vào phần ngôn ngữ và chọn Tiếng Việt. Một số game cần khởi động lại.

    Cảm ơn quý khách. Chơi vui nhé!

    Sổ đặt hàng

    Muốn chơi game nào bằng tiếng Việt thì đặt ở đây, rồi bấm ủng hộ cho những game bạn muốn. Nhóm chọn game dựa trên độ khả thi kỹ thuật và nhân lực, nên xếp hạng cao chưa chắc được làm ngay.

    Sổ đặt hàng

      Đặt một game mới

      Bản demo này lưu đơn đặt hàng và lượt ủng hộ ngay trên trình duyệt của bạn. Khi có backend, dữ liệu sẽ dùng chung cho mọi người. Xóa đoạn này khi ra bản thật.

      Các bản Việt hóa là sản phẩm phi thương mại của cộng đồng người hâm mộ, chỉ gồm phần chữ đã dịch. Bạn cần sở hữu bản game gốc hợp pháp để dùng.

      Tên game và hình ảnh thuộc về nhà phát hành tương ứng. Nếu bạn là chủ sở hữu và muốn gỡ một bản dịch, hãy liên hệ ban quản trị.
